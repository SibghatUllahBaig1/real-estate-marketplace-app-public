## 🎯 The problem

In many markets, property searching still happens through scattered social posts and word of mouth. Customers can't easily filter by price, area or purpose, and agents have no simple way to publish listings and talk to serious buyers.

## 💡 The solution

A purpose-built marketplace app with two experiences in one: **customers** browse, filter and save properties and contact agents instantly; **agents** publish and manage listings and chat with leads.

---

## ✨ Key features

### For customers
| Feature | What it does |
|---|---|
| 🔎 **Search & filters** | Filter by rent/sale, property type, price range and area. |
| ❤️ **Favorites** | Save properties to revisit later. |
| 🖼️ **Rich listing pages** | Image galleries and full property details. |
| 🗺️ **Maps & location** | See properties on a map and search locations with Google Places. |
| 💬 **In-app chat & WhatsApp** | Contact agents in real time, or jump straight to WhatsApp. |

### For agents
| Feature | What it does |
|---|---|
| 🏗️ **Listing management** | Create, edit and delete property listings. |
| 📸 **Multi-image upload** | Upload multiple photos per listing to cloud storage. |
| 👁️ **Visibility toggle** | Switch listings active/inactive without deleting them. |
| 📨 **Lead chat** | Message interested customers directly. |

### Platform
Email/password, **Google** and **Apple** sign-in · push notifications (FCM) · real-time messaging · user profiles with avatars.

---

## 🏗️ Architecture & engineering highlights

- **Role-based experience** — one codebase serving customers and agents with different flows.
- **GetX** for state management, dependency injection and navigation; reactive streams with RxDart.
- **Firebase** — Auth, Cloud Firestore (real-time listings and chat), Cloud Storage (images) and Cloud Messaging.
- **Location features** — Google Maps, geolocation, geocoding and Places autocomplete with runtime permission handling.
- **Smooth, image-heavy UI** — cached network images, SVG assets and onboarding page indicators.
- **Store-ready** — Apple Sign-In for iOS compliance and launcher-icon pipeline for both platforms.
